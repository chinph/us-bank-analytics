# US bank analytics

Independent analyses, each answering one decision for a named reader at a bank. Each has its own notebook, README and app, and can be run alone.

| Analysis | Decision | Reader | Status |
|---|---|---|---|
| [Credit risk](credit-risk) | Which applicants to approve, and at what score cut-off? | Head of consumer credit | Done |
| Complaint monitor | Which complaint themes and companies need attention, and when should an alert fire? | Head of customer experience / compliance | Planned |
| Scam losses | Where do scam losses concentrate, and where should a bank add friction? | Head of fraud strategy | Planned |

Every analysis starts with a research plan and data-access check written before the data is analyzed, and ends with its limits.
