# US bank analytics

Independent analyses, each answering one decision for a named reader at a bank. Each has its own research plan, notebook, README and app, and can be run alone.

| Analysis | Decision | Reader |
|---|---|---|
| [Credit risk](credit-risk) | Which applicants to approve, and at what score cut-off? | Head of consumer credit |
| [Complaint monitor](complaints) | Which complaint streams should be escalated this week, and which alert rule should run? | Head of complaint management |
| [Scam losses](scams) | Where do scam losses concentrate, and where should a bank add friction to payments? | Head of fraud strategy |

Every analysis starts with a research plan and data-access check written before the data is analyzed, logs its predictions up front, and ends with its limits.
